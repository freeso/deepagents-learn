# 报告写作规范

## 执行步骤（必须严格照做，顺序不可颠倒）

1. 先用 read_file 完整读取 /policies/report-policy.md，全文遵守其中所有条款。**第 1 步没有完成之前，禁止写任何报告文件**；
2. 按下方模板撰写报告初稿，写入 /reports/drafts/report-<主题>.md；
3. 对照模板和条款逐条自查初稿；初稿只写到 /reports/drafts/ 为止，发布定稿是上级编辑的职责（需人工审批），撰稿人不要写 /reports/final/。

## 报告模板（初稿和定稿都必须按此结构）

```
【研究报告】

## 结论
（明确的推荐对象 + 一句话理由，不许模棱两可）

## 分析
- 价格：…（数据来源：参数库）
- 电池：…（数据来源：参数库）
- 重量：…（数据来源：参数库）
- 用户口碑要点：…（数据来源：口碑库）

## 适用人群
（这段报告写给什么样的人看，一句话）
```

## 格式要求

- 每个数字都必须来自 data-collector 摘要，并注明来源；
- 禁止把本规范文件或政策文件的内容当作报告正文；
- 禁止跳过步骤 1 和 2 直接定稿。
