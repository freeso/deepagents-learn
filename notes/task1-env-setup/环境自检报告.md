## 三、问题说明（踩坑记录）

本次环境搭建共遇到 4 个坑，完整分析见 [pylibseekdb-macos14-install-issue.md](./pylibseekdb-macos14-install-issue.md)，此处为摘要：

**坑 1：pylibseekdb 在 macOS 14 无法安装（核心问题）**
- 现象：`agentseek task sync` 失败，pylibseekdb 1.4.0.post1 无 macosx_14_0_arm64 wheel
- 根因：依赖链 `agentseek-api[embedded] → pyseekdb → pylibseekdb`，该包要求 macOS arm64 ≥ 15.6，降级亦无解
- 方案：改用 agentseek-api 的 SQLite 持久化后端（详见下节技术说明）

**坑 2：npx skills add 从 GitHub 克隆超时（300s）**
- 方案：`git clone --depth 1` 浅克隆（67M，几十秒）→ `npx skills add <本地路径>` 完成项目级 + 全局安装
- 已装技能：langchain-dev-guide、langsmith-trace（Codex/Claude Code/Cursor 等均生效）

**坑 3：LangSmith CLI not authenticated**
- 根因：CLI 从环境变量读凭证，`.env` 不会自动加载
- 方案：`set -a; source .env; set +a`（或 `langsmith auth login`）
- 另注意：PyPI 的 langsmith 包是 Python SDK，CLI 必须用官方脚本安装

**坑 4：`langsmith trace list --name` 报 400 Bad Request**
- 根因：CLI v0.2.54 的 --name 过滤语法生成有 bug
- 方案：去掉 `--name` 肉眼过滤，或改用 `langsmith run list`

## 四、SQLite 后端方案技术说明

### 4.1 为什么不能用 embedded SeekDB

模板默认 `SEEKDB_EMBED=true`，即 AgentSeek API 在进程内启动嵌入式 seekdb（OceanBase 的 AI 原生搜索数据库）作为 checkpoint 持久化。其 Python 绑定 pylibseekdb 是 C 扩展，官方只发布 `manylinux_2_28_*` 和 `macosx_15_0_arm64+` 的 wheel——本机 macOS 14.4 无法安装，且该约束在旧版本（1.2.0）同样存在，降级不可行。

### 4.2 替代方案：SQLite 元数据后端

阅读 agentseek-api 0.2.3 源码（`agentseek_api/core/database.py` 的 `DatabaseManager.initialize()`）确认存在与 embedded 完全等价的非 embedded 分支：

| 配置组合 | 检查点持久化 | Store | 依赖 |
| --- | --- | --- | --- |
| SEEKDB_EMBED=true | OceanBaseCheckpointSaver | OceanBaseStore | pylibseekdb ❌ 本机不可用 |
| SEEKDB_EMBED=false + METADATA_DB_BACKEND=sqlite | SqliteCheckpointSaver | SqliteStore | aiosqlite（纯 Python，内置） ✅ |

对本地学习而言两者功能等价（run 记录、completed-run 快照均持久化到 SQLite 文件；LangGraph 图检查点为 InMemorySaver，学习场景无影响）。

### 4.3 具体改动（3 个文件）

1. `pyproject.toml`：`agentseek-api[embedded]==0.2.3` → `agentseek-api==0.2.3`；新增 `[[tool.uv.index]]`（官方 PyPI，避免内网镜像缺包）和 `[tool.uv] environments`（仅 darwin-arm64/linux，避免 win32 无效解析）
2. `.agentseek/lifecycle.toml`：`SEEKDB_EMBED` 默认 `false`，新增 `METADATA_DB_BACKEND=sqlite`、`METADATA_DB_URL=sqlite+aiosqlite:///.agentseek/metadata.db`
3. `.env.example`：同步更新并注明原因；macOS 15.6+ 环境可随时改回 embedded 模式

验证：`uv sync` 105 个依赖全部安装；`DatabaseManager` 与 `research_deepagent.agent`（CompiledStateGraph）导入正常；服务双端健康检查通过。
